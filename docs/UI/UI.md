# UI — Sharing Leftovers

## 0. ดีไซน์ (Tone & Theme)

**คอนเซ็ปต์:** *Friendly Community Marketplace* ให้ความรู้สึกอบอุ่น เป็นมิตร ไว้ใจได้ เหมือนตลาดชุมชน ไม่ใช่ระบบธุรกิจ

| องค์ประกอบ | แนวทาง |
|---|---|
| **สีหลัก** | Forest Green `#246B4A` สำหรับปุ่มหลัก ลิงก์ และจุดเน้น |
| **พื้นหลัง** | Warm Neutral `#F7F7F2` ส่วนการ์ดและฟอร์มใช้ขาว `#FFFFFF` |
| **สีเตือน/ยกเลิก** | Terracotta `#B85C38` ใช้กับปุ่มระงับ ยกเลิก และ error |
| **ฟอนต์** | Noto Sans Thai หรือ Prompt (หัวข้อ) + Sarabun (เนื้อหา) |
| **รูปทรง** | มุมโค้ง 12–16px เงาบาง ๆ รูปสิ่งของเป็นพระเอก (aspect ratio 4:3) |
| **ไอคอน** | Emoji ของหมวดหมู่ (🍜 👕 📦 📚) ช่วยให้ดูเป็นกันเอง |
| **Admin** | ใช้ token สีเดียวกัน แต่ layout แน่นขึ้น (Sidebar + ตาราง) และมีแถบสีอ่อนบอกว่าอยู่โหมดหลังบ้าน |

**สีสถานะ (Badge)** ใช้ร่วมกันทั้งระบบ

| สถานะ | ข้อความที่แสดง | โทนสี |
|---|---|---|
| `available` | พร้อมรับ | เขียว |
| `reserved` | จองเต็มแล้ว | เหลืองอำพัน |
| `completed` | ส่งมอบครบแล้ว | เทาเขียว |
| `cancelled` | ยกเลิกแล้ว | เทอร์ราคอตตา |
| `expired` | หมดอายุ | เทา |
| คำขอ `pending` | รอเจ้าของพิจารณา | เหลือง |
| คำขอ `approved` | อนุมัติแล้ว | เขียว |
| คำขอ `rejected` | ไม่ได้รับอนุมัติ | เทอร์ราคอตตา |

## 3. Public Pages

### 3.1 หน้าแรก `/`
**เป้าหมาย:** พาผู้เข้าชมไปค้นหาหรือแบ่งปันให้เร็วที่สุด

**แสดงข้อมูล**
- Hero: หัวข้อ "แบ่งปันสิ่งของ ส่งต่อคุณค่าให้ชุมชน" + ช่องค้นหา
- หมวดหมู่ (ดึงเฉพาะ `isActive`) เป็นชิปไอคอนใหญ่
- "สิ่งของที่เพิ่งแบ่งปัน" Listing Card 6–8 ใบ
- ขั้นตอน 3 ข้อ: ลงประกาศ → ขอรับ → นัดรับ
- (ถ้ามีข้อมูล) สถิติเล็ก ๆ เช่น จำนวนชิ้นที่ส่งต่อแล้ว

**Actions:** พิมพ์ค้นหา · กด "ค้นหาของใกล้ฉัน" (ขอ GPS) · เลือกหมวดหมู่ · เปิดการ์ด · กด "เริ่มแบ่งปัน" (Guest จะถูกพาไป `/auth`)

### 3.2 ค้นหาสิ่งของ `/listings`

```
┌ Header ──────────────────────────────────────────┐
│ [ช่องค้นหา............................] [ค้นหา]   │
├ Filter (ซ้าย/Drawer บนมือถือ) ┬ ผลลัพธ์ ──────────┤
│ หมวดหมู่ ☐☐☐                 │ พบ 24 รายการ  เรียง▼│
│ สภาพ ☐ใหม่ ☐เหมือนใหม่ ...    │ [card][card][card] │
│ พื้นที่: ◉ ใกล้ฉัน (รัศมี ▬●) │ [card][card][card] │
│         ○ เลือกเอง จ./อ./ต.   │      « 1 2 3 »     │
└──────────────────────────────┴───────────────────┘
```

**แสดงข้อมูล:** ผลลัพธ์เป็น Listing Card · จำนวนที่พบ · ตัวกรองที่เลือกอยู่ (เป็นชิปกดลบได้)
**Actions:** ค้นหาข้อความ · กรองหมวดหมู่/สภาพ · สลับโหมด GPS (รัศมี) ↔ เลือกจังหวัด/อำเภอ/ตำบล (Dropdown ต่อเนื่อง) · เรียง (ใหม่ล่าสุด / ใกล้หมดเวลา / ยอดนิยม) · ล้างตัวกรอง · เปลี่ยนหน้า
**กรณีพิเศษ:** ผู้ใช้ปฏิเสธ GPS → แสดงข้อความสุภาพและสลับไปโหมดเลือกพื้นที่เอง · ไม่พบผลลัพธ์ → Empty State พร้อมปุ่ม "ล้างตัวกรอง" · URL เก็บ query เพื่อแชร์/กด Back ได้

### 3.3 รายละเอียดสิ่งของ `/listings/:id`

```
┌ Breadcrumb: หน้าแรก › ค้นหา › โต๊ะทำงาน ──────────┐
│ ┌ แกลเลอรี ───────┐  [พร้อมรับ] 🏷 เฟอร์นิเจอร์  │
│ │  รูปใหญ่         │  โต๊ะทำงานสภาพดี             │
│ │ [▪][▪][▪][▪][▪]  │  สภาพ: ดี · เหลือ 2/3 ชิ้น   │
│ └─────────────────┘  📍 ต.... อ.... จ....        │
│                      ⏳ หมดอายุใน 3 วัน           │
│                      [ ขอรับของชิ้นนี้ ]          │
│ รายละเอียด ........                [🚩 รายงาน]   │
│ ผู้แบ่งปัน: ชื่อ (เบอร์/ที่อยู่ละเอียด 🔒 ซ่อนอยู่)  │
└───────────────────────────────────────────────────┘
```

**แสดงข้อมูล:** รูป 1–5 รูป · ชื่อ · หมวดหมู่ · สภาพ · จำนวนคงเหลือ/ทั้งหมด · คำอธิบาย · พื้นที่คร่าว ๆ · ช่วงเวลานัดรับ · วันหมดอายุ · ชื่อเจ้าของ
**กล่อง "ข้อมูลนัดรับ"** มี 2 แบบ: แบบล็อก 🔒 ("ที่อยู่และเบอร์โทรจะแสดงเมื่อเจ้าของอนุมัติคำขอ") และแบบเปิดเมื่อ `approved` (ที่อยู่ละเอียด เบอร์โทร แผนที่ย่อ ปุ่มคัดลอก)

**สถานะของปุ่มหลักตามผู้ใช้**

| ผู้ดู | ปุ่ม/ข้อความ |
|---|---|
| Guest | **ขอรับของชิ้นนี้** → พาไป `/auth?returnTo=...?action=claim` |
| Member ทั่วไป | **ขอรับของชิ้นนี้** → เปิด Claim Modal |
| เคยขอแล้ว | ปุ่มเทาปิดใช้งาน + "คุณเคยส่งคำขอสำหรับสิ่งของชิ้นนี้ไปแล้ว" + ลิงก์ไป `/reservations/my` |
| เป็นเจ้าของ | แทนปุ่มด้วย "จัดการคำขอ" · "แก้ไข" (ถ้ายังไม่มีคำขอ) · "ยกเลิกประกาศ" |
| Admin | ซ่อนปุ่มขอรับ · แสดง **[⚠️ ยกเลิกประกาศนี้ (Admin)]** สีเทอร์ราคอตตา |
| ประกาศ reserved/completed/cancelled/expired | ปุ่มปิด + แถบข้อความบอกเหตุผล |

**Claim Modal:** ตัวเลือกจำนวน (1 ถึงคงเหลือ) · ช่องข้อความถึงเจ้าของ · ปุ่ม ส่งคำขอ / ยกเลิก · เตือนว่า "ขอได้ครั้งเดียวต่อประกาศ"
**Report Modal:** Dropdown เหตุผล (สแปม / ไม่เหมาะสม / หลอกลวง / ผิดกฎหมาย / ข้อมูลเท็จ / อื่น ๆ) + Textarea + ปุ่มส่ง → Toast "ส่งรายงานเรียบร้อยแล้ว ทีมงานจะตรวจสอบโดยเร็ว" (Guest กดแล้วให้ชวนเข้าสู่ระบบ)

### 3.4 เข้าสู่ระบบ/สมัคร `/auth`
**แสดงข้อมูล:** การ์ดกลางหน้า สลับแท็บ **เข้าสู่ระบบ | สมัครสมาชิก** (ฝั่งซ้ายบน Desktop เป็นภาพ/ข้อความชวนแบ่งปัน)
**ฟิลด์:** Login: อีเมล, รหัสผ่าน · Register: ชื่อ, อีเมล, เบอร์โทร, รหัสผ่าน (ขั้นต่ำ 8 ตัว)
**Actions:** ส่งฟอร์ม · แสดง/ซ่อนรหัสผ่าน · สลับแท็บ
**พิเศษ:** ถ้ามี `returnTo` แสดงแถบ "เข้าสู่ระบบเพื่อขอรับของชิ้นนี้ต่อ" · error แสดงใต้ช่อง และเก็บค่าที่กรอกไว้ · บัญชีถูกระงับ → แจ้ง "บัญชีของคุณถูกระงับการใช้งาน"

### 3.5 วิธีใช้งาน `/help/how-it-works`
ขั้นตอนแบบ Stepper 5 ข้อ (ลงประกาศ → ค้นหา → ขอรับ → อนุมัติ/นัดรับ → ส่งมอบ) · อธิบายกติกาสำคัญ (ขอได้ครั้งเดียวต่อประกาศ, นัดรับเท่านั้น, ข้อมูลติดต่อเปิดเมื่ออนุมัติ) · FAQ แบบ Accordion · ปุ่ม CTA ไปค้นหา/ลงประกาศ

### 3.6 หน้า Error
404 "ไม่พบสิ่งของนี้" · 403 "คุณไม่มีสิทธิ์เข้าหน้านี้" · 500 · ทุกหน้ามีปุ่มกลับหน้าแรก/ค้นหา

## 4. Member Pages

### 4.1 แดชบอร์ด `/dashboard`
**โครงสร้าง:** ทักทาย + สรุปตัวเลขเล็ก ๆ (ประกาศที่เปิดอยู่ · คำขอรอพิจารณาที่ได้รับ · คำขอของฉันที่มีอัปเดต) · แท็บ **คำขอของฉัน | ประกาศของฉัน** (แท็บมีจุดแจ้งเตือน) · ปุ่มลัด "เริ่มแบ่งปัน"

### 4.2 คำขอของฉัน `/reservations/my`
**แสดงข้อมูล:** รายการคำขอเป็นการ์ดแนวนอน: รูปเล็ก · ชื่อสิ่งของ · จำนวนที่ขอ · วันที่ขอ · Badge สถานะ · ข้อความที่ส่งไป · จุดแดง "ใหม่" สำหรับรายการที่ยังไม่อ่าน
- เมื่อ `approved` → ขยายส่วน "ข้อมูลนัดรับ" (ที่อยู่ละเอียด เบอร์โทรเจ้าของ ช่วงเวลา)
- เมื่อ `rejected`/`cancelled` → ข้อความอธิบายสั้น ๆ

**Actions:** กรองตามสถานะ (แท็บชิป: ทั้งหมด/รอ/อนุมัติ/เสร็จสิ้น/อื่น ๆ) · เปิดหน้าสิ่งของ · **ยกเลิกคำขอ** (เมื่อ `pending`/`approved`, มี Confirm) · เมื่อเปิดหน้านี้ Badge ที่ Navbar จะหายไป

### 4.3 ประกาศของฉัน `/users/me/listings`
**แสดงข้อมูล:** ตาราง/การ์ด: รูป · ชื่อ · Badge สถานะ · คงเหลือ/ทั้งหมด · วันหมดอายุ · จำนวนคำขอ (แยก "รอพิจารณา" ให้เด่น)
**Actions:** กรองตามสถานะ · **ดูคำขอ** · **แก้ไข** (ถ้ามีคำขอแล้วปุ่มเป็นสีเทา + Tooltip "มีคนขอแล้ว จึงแก้ไขไม่ได้") · **ยกเลิกประกาศ** (Confirm Dialog อธิบายว่าคำขอที่ค้างจะถูกยกเลิกทั้งหมด) · เปิดดูหน้าสาธารณะ · เริ่มแบ่งปันใหม่

### 4.4 ลงประกาศ `/listings/new` และแก้ไข `/listings/:id/edit`
ฟอร์มแบ่งเป็นการ์ดตอน ๆ ให้ไม่ดูยาวเกินไป

| ตอน | ฟิลด์ |
|---|---|
| ข้อมูลสิ่งของ | ชื่อ · หมวดหมู่ (Dropdown) · สภาพ (Radio ชิป) · จำนวน (Stepper ≥ 1) · รายละเอียด (บังคับ) |
| รูปภาพ | ช่องใส่ URL ได้ 1–5 รูป · Preview ทันที · ปุ่มลบ/จัดลำดับ · แจ้ง error ถ้า URL ไม่ใช่ http(s) หรือรูปโหลดไม่ได้ |
| การนัดรับ | แสดงชัดว่า **"นัดรับด้วยตนเองเท่านั้น"** · จังหวัด/อำเภอ/ตำบล (เปิดสาธารณะ) · ที่อยู่ละเอียด (ซ่อนจนกว่าอนุมัติ) · ปุ่มใช้ตำแหน่งปัจจุบัน · ช่วงเวลาสะดวกนัดรับ |
| วันหมดอายุ | Date-time picker (ต้องเป็นอนาคต) |

**Actions:** บันทึก/เผยแพร่ · ยกเลิก · Validation แบบ inline และกันกดซ้ำ
**หน้าแก้ไข:** ถ้ามีคำขอแล้ว แสดงแถบล็อก 🔒 "ประกาศนี้มีผู้ขอรับแล้ว จึงแก้ไขไม่ได้ หากต้องการเปลี่ยนแปลงให้ยกเลิกประกาศแล้วลงใหม่" และปิดทุกช่อง เหลือปุ่ม "ยกเลิกประกาศ"

### 4.5 จัดการคำขอที่ได้รับ `/listings/:id/reservations`
**ส่วนหัว:** สรุปประกาศ (รูปเล็ก ชื่อ Badge) + ตัวเลข **คงเหลือ / จองแล้ว / ส่งมอบแล้ว** (แยกให้เห็นชัดว่าคำขอ pending ยังไม่ตัดสต็อก)
**รายการคำขอ:** ชื่อผู้ขอ · จำนวนที่ขอ · ข้อความ · วันที่ · Badge สถานะ
**ปุ่มตามสถานะ**

| สถานะคำขอ | ปุ่ม |
|---|---|
| `pending` | **อนุมัติ** (เขียว) · **ปฏิเสธ** (เส้นขอบ) |
| `approved` | **ยืนยันส่งมอบแล้ว** (เขียว) · **ยกเลิกนัด** (เทอร์ราคอตตา) · แสดงข้อมูลติดต่อผู้ขอ |
| `completed` / `rejected` / `cancelled` | ไม่มีปุ่ม แสดงวันเวลาที่เกิดเหตุการณ์ |

**พิเศษ:** ถ้าอนุมัติแล้วของไม่พอ ให้ Toast อธิบายและรีเฟรชจำนวนล่าสุด · ถ้าคำขอถูกจัดการไปแล้ว ให้แสดงสถานะล่าสุดแทน error กว้าง ๆ · ทุกการกระทำสำคัญมี Confirm Dialog

### 4.6 โปรไฟล์ `/users/me`
**แสดง:** อวาตาร์ · ชื่อ · อีเมล (🔒 แก้ไม่ได้) · เบอร์โทร · ที่อยู่ประจำตัว (จังหวัด/อำเภอ/ตำบล) · ตำแหน่ง
**Actions:** แก้ไขและบันทึก · ไปหน้าเปลี่ยนรหัสผ่าน · (ส่วน Danger Zone) ปิดบัญชีของฉัน พร้อม Confirm

### 4.7 เปลี่ยนรหัสผ่าน `/auth/password`
ฟิลด์: รหัสผ่านปัจจุบัน · รหัสผ่านใหม่ (ตัวบอกความแข็งแรง ขั้นต่ำ 8 ตัว) · ยืนยันรหัสผ่านใหม่ → บันทึก → Toast สำเร็จ

## 5. Admin Pages

**Layout:** Sidebar ซ้าย (ภาพรวม · ประกาศ · รายงาน · สมาชิก · หมวดหมู่) + พื้นที่ตารางด้านขวา · เมนูรายงานมีตัวเลขจำนวนที่รอดำเนินการ

### 5.1 ภาพรวม `/admin`
การ์ดสถิติ: ผู้ใช้ทั้งหมด · ประกาศที่เปิดอยู่ · รายงานรอจัดการ · บัญชีที่ถูกระงับ · รายการ "รายงานล่าสุดที่รอตรวจ" (คลิกไปหน้ารายงาน) · ทางลัดไปแต่ละแท็บ

### 5.2 จัดการประกาศ `/admin/listings`
**ตาราง:** รูปเล็ก · ชื่อ · เจ้าของ · หมวดหมู่ · Badge สถานะ · คงเหลือ/ทั้งหมด · จำนวนคำขอ · วันที่ลง
**Actions:** ค้นหา · กรองสถานะ/หมวดหมู่/สมาชิก · เปิดดูรายละเอียด (Drawer หรือหน้าสาธารณะ) · **ยกเลิกประกาศ** (Confirm: แจ้งผล Cascade — คำขอค้างจะถูกยกเลิก ของที่จองไว้จะคืนสต็อก และกู้คืนไม่ได้)
**ไม่มี** ปุ่มแก้ไข/ลงประกาศ

### 5.3 คิวรายงาน `/admin/reports`
**ตาราง:** ประกาศที่ถูกรายงาน · ผู้รายงาน · เหตุผล (ชิปสี) · วันที่ · Badge สถานะ (pending/reviewing/resolved/rejected)
**Detail Drawer:** รายละเอียดที่ผู้ใช้เขียน · พรีวิวประกาศ (รูป/เนื้อหา) · ประวัติสถานะ
**Actions:** กรองตามสถานะ/เหตุผล · **[กำลังตรวจสอบ]** · **[ยกเลิกประกาศ]** (แล้วถามต่อ "ปิดตั๋วเป็น resolved เลยไหม") · **[ปิดตั๋ว → resolved]** · **[ปฏิเสธรายงาน → rejected]** (กรณีแจ้งเท็จ ไม่แตะประกาศ) · ปุ่มลัด "ระงับบัญชีเจ้าของ"

### 5.4 จัดการสมาชิก `/admin/users`
**ตาราง:** ชื่อ · อีเมล · วันที่สมัคร · สถานะ (ใช้งาน/ถูกระงับ) · จำนวนประกาศ
**Actions:** ค้นหาชื่อ/อีเมล · กรองสถานะ · **[ระงับบัญชี]** (แดง) → Modal ยืนยัน **บังคับกรอกเหตุผล** และแจ้งว่า Session จะถูกตัดทันที · **[ปลดระงับ]** (เขียว)
**ห้าม:** ไม่มีตัวเลือกเปลี่ยน role หรือแต่งตั้งแอดมินใน UI

### 5.5 จัดการหมวดหมู่ `/admin/categories`
**ตาราง/การ์ด:** ไอคอน · ชื่อ · slug · คำอธิบาย · จำนวนประกาศที่ใช้ · สวิตช์เปิด/ปิด
**Actions:** **เพิ่มหมวดหมู่** (Modal: ชื่อ, slug อังกฤษ, คำอธิบาย, Emoji picker) · **แก้ไข** (มีข้อความ "ชื่อใหม่จะเปลี่ยนในทุกประกาศทันที") · **ลบ/ปิดใช้งาน** (ถ้ามีประกาศใช้อยู่ ระบบจะแจ้งว่า "จะถูกปิดใช้งานแทนการลบ")

## 6. หมายเหตุสำหรับการทำจริง

- **ข้อยุติสถานะคำขอเมื่อประกาศถูกยกเลิก (Cascade Cancellation):**
  1. คำขอที่ค้างอยู่ทั้งหมด (ทั้ง `pending` และ `approved`) จะเปลี่ยนเป็น **`cancelled`** ทั้งหมด โดยฝั่ง UI แสดงข้อความ "ประกาศนี้ถูกยกเลิก" ให้ผู้ขอเข้าใจตรงกันอย่างชัดเจน
- **ลำดับทำหน้าที่แนะนำ:** `/listings` + `/listings/:id` → `/auth` → `/listings/new` → `/reservations/my` + จัดการคำขอ → Admin
- **Responsive:** บนมือถือ ใช้ Filter เป็น Drawer ด้านล่าง, ปุ่ม "ขอรับของ" แบบ Sticky ชิดล่างหน้ารายละเอียด, ตาราง Admin เลื่อนแนวนอนในกรอบของตัวเอง
- **Accessibility:** ตรวจ Contrast ตัวหนังสือขาวบนเขียว `#246B4A` และตัวอักษรเล็กบน Terracotta · ทุกรูปมี `alt` · Modal ต้อง focus trap และปิดด้วย Esc
